서울 자치구 위치 지도 — 방식 비교

A: Static Map만 · B: GeoJSON SVG만 · C: Static Map + SVG 오버레이 · D: Dynamic Map + GeoJSON Data 레이어

A. Static Map (이미지 1장)

네이버 실사 지도 + 마커만. 경계선 없음. API 호출 1회, JS 불필요, 가장 가벼움.

B. SVG (GeoJSON 렌더링)

API 호출 0회. 경계가 가장 또렷하고 크롤러가 텍스트를 읽음. 대신 실제 지형·도로·지명이 없음.

C. Static Map + SVG 오버레이

실사 지도 위에 경계선을 얹음. 정적이라 가볍지만 좌표 정렬이 어긋나면 보정 필요.

D. Dynamic Map + GeoJSON ★

네이버 검색 결과 화면과 가장 비슷함. 확대·이동 가능, 정렬 오차 없음. JS 필요, 호출량 소모.
